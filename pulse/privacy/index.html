Pulse Privacy Policy

Pulse is a private data-reporting tool built and used internally by Krida LLC. It is not a public-facing app or service — this page explains what it accesses and why, for anyone reviewing its use of connected platform APIs.

Last updated July 28, 2026 Operator Krida LLC Contact contact@kridallc.com

Pulse reads performance data that already belongs to Krida LLC — its own app install counts, its own social posts, its own ad spend — and writes it to local files so it can be reviewed internally. It does not collect information about individual end users of Krida LLC's apps, and it does not share, sell, or publish anything on Krida LLC's behalf.

01

What Pulse is

Pulse is a small internal tool that pulls marketing and performance data from the platforms Krida LLC already uses — Google Play Console, Apple App Store Connect, YouTube, Meta (Facebook and Instagram), and Meta Ads — into local spreadsheet files. It runs only when a member of Krida LLC triggers it manually; there is no server, no hosted backend, and no public interface.

02

Data Pulse accesses

Every data source below belongs to Krida LLC as the account holder or Page administrator. None of it is personal information about individual people who use Krida LLC's apps.

  • Meta — Facebook Pages & Instagram accounts. Post captions and engagement counts (likes, comments, shares) for Krida LLC's own Pages and Instagram accounts.
  • Meta Marketing API. Daily spend, impressions, and clicks for Krida LLC's own ad accounts.
  • Google Play Console. Daily install and uninstall counts for Krida LLC's own Android apps.
  • Apple App Store Connect. Daily download counts for Krida LLC's own iOS apps.
  • YouTube. Public view, like, and comment counts on videos from Krida LLC's own channels.
03

What Pulse does not do

  • It does not collect or process personal data belonging to end users of Krida LLC's apps — no names, emails, device identifiers, precise location, or individual in-app activity.
  • It does not use any data for advertising, profiling, or targeting.
  • It does not sell, share, or transfer data to any third party.
  • It does not post, publish, or modify anything through any connected account — every connection it makes is read-only.
04

Where data is stored

Pulled data is written to local spreadsheet files on a computer Krida LLC owns and controls. Nothing is uploaded to a cloud service, external database, or public server as part of Pulse's operation. Files are kept only as long as they're useful for internal reporting and are deleted at Krida LLC's discretion.

05

Access & authentication

Pulse authenticates using credentials Krida LLC generates and controls directly — a Google service account, an Apple API key, a YouTube API key, and a Meta system-user access token — each scoped only to Krida LLC's own accounts and assets. No third party has access to these credentials or to the data Pulse retrieves.

06

Data deletion

Because Pulse does not collect or store any personal data belonging to end users (see Section 3), there is no end-user data to request deletion of. The only data Pulse retrieves — Krida LLC's own install counts, ad spend, and post engagement figures — is retained solely by Krida LLC and can be deleted at any time by simply removing the local files it writes. Anyone with questions about this can reach us at contact@kridallc.com.

07

Changes to this policy

This page is updated whenever Pulse's data sources change. The date at the top reflects the current version.
